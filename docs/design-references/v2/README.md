# Worksite Ops UI Reference Images

These files are implementation references for the mobile-first Worksite Operations Platform redesign.

- `mobile/foreman/`: Foreman operational screens
- `mobile/ceo/`: CEO management screens
- `mobile/shared/`: Shared sheets, access states, loading, and errors
- `desktop/foreman/`: Foreman desktop/tablet references
- `desktop/ceo/`: CEO desktop references
- `desktop/shared/`: Desktop authentication/access states

The images preserve the approved business scope. They are visual guidance, not permission to change domain rules or data models.
